#### Reflection

This week strengthened my understanding of operating systems and introduced more practical Windows administration.

The most useful practical lesson was understanding that troubleshooting is not always performed through a single tool. Task Manager, Services, and Event Viewer provide different information, and combining them can provide a clearer view of what is happening on a Windows system.

This is useful preparation for later cybersecurity work involving Windows logs, endpoint activity, SIEM investigations, and incident response.
