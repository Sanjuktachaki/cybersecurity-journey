# Week 4 Notes — IPv4, Subnetting, Ethernet and ARP

## 1. IPv4 Structure

IPv4 is a topic covered this week as part of the networking foundation.

I studied the structure of an IPv4 address and how IPv4 addressing is used to identify devices on a network.

## 2. Subnet Masks and CIDR

I studied subnet masks and CIDR notation.

I also worked through subnetting calculations and practiced the calculations rather than only learning the definitions.

The main focus was understanding how subnetting divides networks and how the CIDR prefix relates to the network and host portions of an IPv4 address.

## 3. MAC and Ethernet

I studied MAC addresses and Ethernet as part of understanding communication at the local network level.

This connected the addressing concepts from IPv4 with Ethernet traffic.

## 4. ARP

I studied ARP and how it is used to connect IP addressing with MAC addressing on a local network.

I also observed ARP traffic practically using Wireshark during the lab.

## 5. Security Applications

I studied the security applications of these networking concepts.

Understanding IPv4, subnetting, MAC addresses, Ethernet and ARP provides a foundation for analysing network traffic and investigating network behaviour.

## Weekly Takeaway

This week focused on understanding how IPv4 addressing works, how networks can be divided using subnetting and CIDR, and how local network communication uses MAC addresses, Ethernet and ARP.

The practical Wireshark exercises helped connect the concepts with actual network traffic.
