\## Key Learning



When a computer is turned on, it first checks the hardware through **BIOS/UEFI (POST)** and then starts the **bootloader**, which loads the operating system.



The main hardware I learned about is **CPU, RAM and storage**. The CPU processes things, RAM is used for things currently running, and storage keeps files permanently. When I open an app, it is loaded from **storage -> RAM -> CPU.**



The **OS** like **Windows or Linux** manages the hardware, programs and files. Different OSs use different **file systems**, such as **NTFS and ext4**.



I also learned that a **program** stored on the disk isn't a **process** until it is actually running. Some processes are visible, while others run in the background as **services**.



In simple words: **Power on -> hardware check -> OS loads -> programs run**.



\## Cybersecurity Relevance



Understanding the **operating system, processes, services and file systems** is important in cybersecurity because most security problems happen somewhere in these areas. If I know how a normal computer works, I can notice when something looks unusual. For example, a **suspicious process or service** could be running in the background, or an important **file or folder** could have been changed. Knowing how Windows and Linux manage these things gives me the basic understanding I need later for **finding threats, investigating incidents and securing systems.**
