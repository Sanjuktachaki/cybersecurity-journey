* Service startup
* Windows Services console
* Service management

#### Tools / Interfaces Used

* Windows Services

## Practical Work

I opened the Windows Services interface and worked with the available service-management functions.

I examined how Windows services are represented and managed through the Services interface and connected the practical interface with the Service Control Manager concepts studied during the week.

I also worked through the service-management activities required by the lab.

## Cybersecurity Relevance

Windows services are relevant to security analysis because services can be associated with system functionality, persistence, system activity, and troubleshooting.

Understanding normal service management provides a foundation for recognizing unusual or suspicious service-related activity later during security investigations.



# Lab 2 — Using Windows Administrative Tools Together During Troubleshooting

## Objective

Learn how Windows administrative tools can be used together during troubleshooting.

## Tools Used

* Task Manager
* Services
* Event Viewer

## Practical Work

I completed the troubleshooting activities using Task Manager, Services, and Event Viewer.

Instead of examining the system through only one tool, I used the different administrative interfaces to obtain different types of information about system activity.

### Task Manager

I used Task Manager to inspect running system activity and processes.

### Services

I used the Services interface to inspect Windows services and their management information.

### Event Viewer

I used Event Viewer to inspect recorded Windows events and use the available event information during troubleshooting.

## Result

I completed the practical troubleshooting activities and recorded the observations and results from the tools used.

The lab demonstrated that Windows troubleshooting can involve combining information from multiple administrative tools.

## What I Learned

The main lesson from this lab was that different administrative tools provide different views of the same system.

Task Manager helps with process and activity information.

Services helps with Windows service information and management.

Event Viewer provides recorded event information.

Using these sources together creates a more useful picture when investigating a Windows system problem.

## Cybersecurity Relevance

The ability to examine processes, services, and event logs is directly relevant to security analysis.

These concepts provide a foundation for later work involving:

* Windows event analysis
* SIEM investigations
* Endpoint investigations
* Incident response
* Detection
* Threat hunting
